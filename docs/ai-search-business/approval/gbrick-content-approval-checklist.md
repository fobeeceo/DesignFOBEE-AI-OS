### 채널별 복사 방법

| 채널 | 사용할 섹션 | 복사 방법 |

| 네이버 블로그 | 본문 전체 (YAML frontmatter 제외) | Markdown → 네이버 스마트에디터 붙여넣기 |
| 구글 사업장 | §2-X 구글/네이버 사업장 소개 초안 | 직접 복사 붙여넣기 |
| 네이버 플레이스 | §2-X 네이버 플레이스 설명 초안 | 직접 복사 붙여넣기 |
