# AI 검색 노출 진단 서비스 — 파일럿 제안서 초안
**DesignFOBEE** | AI Search Diagnosis for Interior & Café Brands

---

## 귀사 소개에 앞서

요즘 고객들은 "강남 카페 추천", "판교 감성 인테리어 카페" 같은 질문을 AI에 묻습니다.  
ChatGPT, Gemini, Perplexity가 추천하는 곳이 방문지가 됩니다.  

귀사의 브랜드는 지금 그 AI 답변에 나오고 있을까요?

---

## 1. 서비스 개요

**AI 검색 노출 진단**은 소비자가 AI에 검색했을 때 귀사 브랜드·매장이 어떻게 인식되는지 측정하고, 노출률을 높이기 위한 콘텐츠 개선을 지원하는 서비스입니다.

**우리가 이 서비스를 제공하는 이유**:  
DesignFOBEE는 GBRICK Coffee를 직접 운영하면서 동일한 AI 검색 문제를 경험했습니다. 직접 시스템을 구축하고 측정했으며, 그 결과를 외부 브랜드에도 적용합니다.

---

## 2. 진단 범위

### 포함 항목

| 항목 | 내용 |
|---|---|
| AI 노출 진단 | Google Gemini (검색 그라운딩) 기준, 20개 맞춤 질문 |
| 질문 설계 | 귀사 상권·메뉴·특성을 반영한 20문항 커스터마이징 |
| 결과 분류 | MENTIONED / NOT_MENTIONED / FAILED 4상태 분류 |
| 사실 오류 확인 | AI 응답 중 잘못된 주소·메뉴명·정보 확인 |
| 콘텐츠 개선 초안 | 노출률 향상을 위한 텍스트 초안 3건 제공 |
| 기준선 보고서 | 진단 결과 요약 보고서 (문서 형태) |
| 재측정 1회 | 콘텐츠 게시 후 개선 효과 측정 (게시 2–4주 후) |

### 제외 항목

| 항목 | 사유 |
|---|---|
| ChatGPT, Perplexity, 네이버 AI 등 | 별도 측정 모듈 필요 (추가 패키지) |
| 콘텐츠 직접 게시 | 채널별 계정 접근 권한이 귀사에 있음 |
| SEO (검색 엔진 최적화) | 별도 서비스 영역 |
| 광고·유료 노출 | 본 서비스 범위 외 |
| 성과 보장 | AI 알고리즘 변화에 따른 결과 변동 보장 불가 |

---

## 3. 수행 단계

| 단계 | 작업 | 기간 |
|---|---|---|
| **1. 정보 수집** | 브랜드명·주소·메뉴·상권 파악, 질문 20개 설계 | 3–5일 |
| **2. 기준선 측정** | 개선 전 AI 노출 현황 측정·분류 (1회) | 1일 |
| **3. 결과 분석** | 사실 오류 확인, 노출 기회 누락 영역 파악 | 2–3일 |
| **4. 콘텐츠 초안** | 노출 향상 목적 텍스트 초안 3건 작성 | 5–7일 |
| **5. 고객 확인** | 사실 확인 및 수정 | 3–5일 |
| **6. 콘텐츠 게시** | 귀사 채널에 직접 게시 (귀사 담당) | 귀사 일정 |
| **7. 재측정** | 게시 2–4주 후 개선 효과 측정 (1회) | 1일 |
| **8. 최종 보고서** | 개선 전·후 비교 결과 보고서 | 2–3일 |
| **합계** | | **약 4–6주** |

---

## 4. 산출물

1. **AI 검색 노출 진단 보고서** (기준선): 20문항 결과, 사실 오류, 노출 기회 분석
2. **콘텐츠 개선 초안 3건**: 게시 가능한 텍스트 형태, 사실 확인 체크리스트 포함
3. **재측정 결과 보고서** (개선 후): 기준선 대비 변화 비교
4. **측정 기준서**: 향후 자체 측정 시 활용 가능한 기준 문서

---

## 5. 가격 안내

> **이 항목은 대표 확인 후 확정합니다. 아래는 검토용 범위입니다.**

### 파일럿 패키지 (1개 브랜드, 1개 AI 서비스)

| 구성 | 내용 |
|---|---|
| 기준선 진단 1회 + 콘텐츠 초안 3건 + 재측정 1회 | 파일럿 기본 구성 |
| 가격 범위 (검토 중) | 대표 확인 후 확정 |
| API 직접 비용 | 실비 정산 (Gemini 20문항 1회 약 $0.015) |

> **중요**: 이 서비스는 AI 노출률 상승을 보장하지 않습니다. AI 알고리즘과 웹 색인은 지속적으로 변화합니다. 콘텐츠 게시 후 개선이 나타나는 데 수 주에서 수 개월이 걸릴 수 있습니다. 성과 측정 기준과 한계를 계약 전 명확히 안내합니다.
