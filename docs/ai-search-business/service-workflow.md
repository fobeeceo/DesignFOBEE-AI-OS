# AI 검색 노출 개선 서비스 — 운영 워크플로우
버전: 1.0 · 작성일: 2026-10-24

---

## 1. 전체 흐름 (고객 등록 → 월간 보고)

```
[1] 고객 등록         → AI 직원 (데이터 입력)
[2] 진단 실행         → AI 직원 (자동 측정)
[3] 리포트 생성       → AI 직원 (자동 생성)
[4] 대표 검토         → 대표 (승인 지점 #1)
[5] 고객 전달         → 대표 (대외 발송)
[6] 원인 분석         → AI 직원 (가설 생성)
[7] 개선안 작성       → AI 직원 (콘텐츠 초안)
[8] 대표 검토         → 대표 (승인 지점 #2)
[9] 고객 승인         → 고객 (대표가 전달)
[10] 개선 실행        → AI 직원 + 대표 (외부 업로드는 대표)
[11] 재측정           → AI 직원 (자동 측정)
[12] 성과 보고        → AI 직원 (자동 생성) + 대표 검토
[13] 월간 계약 제안   → 대표
[14] 월간 관리 루프   → [11] → [12] → [13] 반복
```

---

## 2. 단계별 상세

### [1] 고객 등록
- **담당**: AI 직원 (입력 대행) + 대표 (정보 제공)
- **작업**: HQ `/hq/ai-search`에 사업체 등록 (브랜드명·주소·메뉴·URL 등)
- **완료 기준**: `factCheckStatus = CONFIRMED` — 사실 확인 완료 후 진단 시작

### [2] 진단 실행
- **담당**: AI 직원
- **작업**: Gemini Google Search grounding으로 20문항 자동 측정
- **소요 시간**: 약 10~15분 (타임아웃 포함)
- **대표 개입 없음** — 측정은 완전 자동

### [3] 리포트 생성
- **담당**: AI 직원
- **작업**: 측정 결과 → 카테고리별 노출률 · 문제 질문 목록 · 개선 권고 초안
- **저장**: Supabase DB + 리포트 파일
- **대표 개입 없음**

### [4] 대표 검토 (승인 지점 #1 — 고객 전달 전)
- **담당**: 대표
- **확인 항목**:
  - 수치가 정확한가 (FAILED를 성공으로 잘못 계산하지 않았는가)
  - 고객에게 전달해도 되는 내용인가
  - 가격·비용 관련 내용이 포함되어 있지 않은가 (포함 시 별도 검토)
- **결정**: 전달 승인 / 수정 요청
- **대표만 할 수 있는 이유**: 대외 문구 최종 확인 (§16-A 승인 규칙)

### [5] 고객 전달
- **담당**: 대표
- **방법**: 이메일·미팅·카카오 등 고객 선호 채널
- **AI 직원 역할**: 전달용 요약 메시지 초안 작성 대기

### [6] 원인 분석
- **담당**: AI 직원
- **작업**:
  - 미언급 질문 패턴 분석
  - 키워드 갭 (질문 키워드 vs 브랜드 보유 콘텐츠) 파악
  - 개선 가설 목록 작성
- **산출물**: `improvement-hypotheses.md` (내부 문서)

### [7] 개선안 초안 작성
- **담당**: AI 직원
- **작업**:
  - 미언급 질문별 개선 콘텐츠 초안 (블로그 글·FAQ·메뉴 설명 등)
  - 어디에 올릴지 (네이버 블로그·Google Business Profile·인스타그램 등)
- **대표 개입 없음**

### [8] 대표 검토 (승인 지점 #2 — 실행 전)
- **담당**: 대표
- **확인 항목**:
  - 콘텐츠 내용이 사실인가 (없는 내용 창작 금지 원칙)
  - 브랜드 톤과 맞는가
  - 실행 우선순위
- **대표만 할 수 있는 이유**: 대외 콘텐츠 최종 확인

### [9] 고객 승인
- **담당**: 대표 (고객과 소통)
- **작업**: 개선 콘텐츠를 고객에게 확인 받음
- **AI 직원 역할**: 고객 피드백 반영한 수정본 재작성

### [10] 개선 실행
- **담당**: AI 직원 (내부 DB·파일 업로드) + 대표 (외부 플랫폼 게시)
- **외부 플랫폼 업로드는 대표가 직접**: Google Business Profile·네이버·SNS 등
- **이유**: 외부 서비스 계정 접근은 대표만 (§16-A 승인 규칙)

### [11] 재측정
- **담당**: AI 직원
- **작업**: 개선 실행 4주 후 동일 20문항 재측정
- **비교 기준**: 직전 측정 결과와 같은 질문 코드로 비교

### [12] 성과 보고
- **담당**: AI 직원 (자동 생성) + 대표 검토
- **포함 내용**:
  - 개선 전/후 노출률 비교
  - 회복된 질문·신규 노출 질문
  - 여전히 미노출인 질문 및 다음 개선 권고
- **승인 지점**: 고객 전달 전 대표 검토 (승인 지점 #1과 동일)

### [13] 월간 계약 제안
- **담당**: 대표
- **타이밍**: 개선 결과 확인 후 자연스럽게
- **제안 근거**: 실측 Before/After 데이터

### [14] 월간 관리 루프
- [11] 재측정 → [12] 성과 보고 반복
- 월 1회 자동 측정·자동 리포트
- 대표는 검토·전달만

## 3. AI 직원 vs 대표 역할 분리

| 구분 | AI 직원 (자동) | 대표 (승인·실행) |
|---|---|---|
| 측정 | 자동 실행 | - |
| 리포트 생성 | 자동 생성 | 검토 후 전달 |
| 원인 분석 | 가설 작성 | - |
| 콘텐츠 초안 | 작성 | 검토·승인 |
| 외부 플랫폼 게시 | 불가 | **직접 게시** |
| 고객 소통 | 초안 작성 | **실제 소통** |
| 비용·가격 결정 | 정보 제공 | **결정** |
| DB 저장 | 자동 | - |
