(`public/gbrick-menu.html` 라인 149–152)

| 가격 | ₩3,500 (두 종류 동일) | gbrick-menu.html L149, L151 |

| 예가체프 설명 | "이디오피아 예가체프 원두 (과일 산미)" | gbrick-menu.html L152 |

| 리필 | ₩1,500 | gbrick-menu.html L199 |

#### 충돌 항목
| SSOT 값 | 공개 메뉴 값 | 충돌 내용 |
|---|---|---|
| `beans: "자체 블렌딩 원두"` | 스페셜티 원두 / 예가체프 원두 — **별도 선택** | "자체 블렌딩"이 두 가지 중 어느 것인지, 아니면 별개 블렌드가 있는지 불명확 |

**AI 판단**: 공개 메뉴 HTML의 `스페셜티 원두`가 SSOT의 `자체 블렌딩 원두`일 가능성이 높으나, 확인 없이 단정하지 않는다 (§0-2 원칙 2).

#### Google 등록 및 AI 검색용 사용 가능 문구
- ✅ "핫/아이스 모두 제공"
- ✅ "원두 선택: 스페셜티 (고소한 맛) 또는 예가체프 (과일 산미)"
- ✅ "디카페인 변경 가능 (+500원)"
- ❌ "자체 블렌딩 원두" — 대표 확인 전 사용 불가

### 3-2. 수제 자몽티 — ⚠️ WARN

#### 공개 메뉴에서 확인된 사실

**[A] 수제 에이드 카테고리** (`public/gbrick-menu.html` L167–168)
| 항목 | 확인 값 |
|---|---|
| 메뉴명 | 수제 에이드: 레몬 / **자몽** / 오미자 / 패션후르츠 |
| 가격 | ₩5,500 |
| 제공 온도 | 아이스(Iced)만 |
| 재료 | 직접 만든 수제청 + 후지산 탄산수 + 얼음 |

**[B] 수제티 카테고리** (`public/gbrick-menu.html` L190)
| 항목 | 확인 값 |
|---|---|
| 메뉴명 | 수제티: **생자몽** / 오미자 / 레몬 / 유자 / 진저 |
| 가격 | ₩6,000 |
| 제공 온도 | 핫(Hot) + 아이스(Iced) |
| 재료 | 미명시 (메뉴명만) |

#### 충돌 항목
SSOT `mainMenu`의 "수제 자몽티"가 위 [A]인지 [B]인지 불명확. 두 메뉴가 다른 카테고리·가격·온도를 가짐.

#### 현재 초안 상태
`docs/ai-search-business/drafts/gbrick/03-menu-*.md` L113에 "자몽티 수제 여부 — **수제** (대표 확인 2026-10-26)"으로 기록됨. 하지만 어느 버전인지는 여전히 미확인.

#### Google 등록 및 AI 검색용 사용 가능 문구 (공통 확인 사항)
- ✅ 자몽을 사용한 수제 음료 존재
- ✅ 에이드 버전: 아이스, ₩5,500, 탄산 베이스, 직접 만든 수제청
- ✅ 수제티 버전: 핫/아이스, ₩6,000, 생자몽 베이스
- ❌ "수제 자몽티"를 단일 메뉴로 단정하는 문구 — 대표 확인 전 사용 불가
