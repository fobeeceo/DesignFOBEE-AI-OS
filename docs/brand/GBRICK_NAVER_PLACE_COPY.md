## 2. 개정안

```
지브릭커피(GBRICK Coffee)는 은평뉴타운 중심, 은평한옥마을 바로 옆에 있는 스페셜티 커피 전문점입니다. 감성적인 공간에서 여유와 깊은 커피 맛을 함께 즐기실 수 있습니다.

■ 커피
매일 직접 로스팅한 신선한 원두로 내리는 핸드드립과 더치커피가 대표 메뉴입니다. 아메리카노는 고소한 맛의 스페셜티 원두와 과일 산미의 예가체프 원두 중에서 고르실 수 있고, 핫·아이스 모두 가능합니다.

■ 수제 음료
싱싱한 자몽을 매일 직접 손질해 만드는 수제 자몽티(수제티 생자몽)와 자몽 에이드, 직접 만든 수제청(자몽·유자·진저) 음료, 리얼과일 라씨를 준비합니다.

■ 계절 메뉴
여름에는 직접 만든 팥과 인절미, 우유얼음으로 만드는 수제 팥빙수(눈꽃빙수), 겨울에는 레드와인과 과일을 베이스로 한 무알콜 뱅쇼를 선보입니다.

■ 디저트·베이커리
허니브레드, 갈릭브레드, 크로크무슈, 인절미토스트, 스콘, 루벤 쿠키, 팥빵.

■ 단체 주문·배달
단체 주문과 배달이 가능합니다. 하루 전, 늦어도 5시간 전까지 주문해 주세요.
문의 02-517-1474

■ 위치
서울 은평구 연서로48길 12, 제각말푸르지오 5단지 상가 101호(1층)

마음이 편안해지고 대화하기 좋은 카페를 찾으신다면 지브릭커피로 오세요. 진심을 담은 커피와 수제 음료, 디저트로 한 잔의 여유를 선물해 드립니다.
```

## 3. 기존 문구에서 바꾼 것과 게시 전 확인

### 바꾼 것

| 기존 | 개정 | 이유 |
|---|---|---|
| 자체블렌딩원두 | 스페셜티 원두 / 예가체프 원두 선택 | 2026-11-04 사실 정정 (SSOT) |
| 수제 눈꽃빙수 | 수제 팥빙수(눈꽃빙수) | 공식 메뉴명은 "수제 팥빙수" (대표 확인 2026-10-26). 검색어 "눈꽃빙수"는 괄호로 유지 |
| 누적 판매 10,000개! | 삭제 | 사람이 갱신해야 하는 수치는 대외 지표로 쓰지 않는다 (CLAUDE.md §0-2 원칙 5). 근거 자료도 확인하지 못함 |

| (없음) | 단체 주문·배달, 스콘·루벤 쿠키·팥빵, 주소, 전화번호 | 대표 진술 추가 + AI가 답할 때 쓰는 기본 정보 보강 |

### 게시 전 대표 확인 (4건)

- [ ] **매일 직접 로스팅** — 지금도 매장에서 매일 로스팅하는가. 공개 메뉴판과 SSOT에는 로스팅 관련 기록이 없다.
- [ ] **허니브레드·갈릭브레드·크로크무슈·인절미토스트** — 지금도 판매하는가. 공개 메뉴판에 없다.
- [ ] **단체 배달 주문 시한** — "하루 전, 늦어도 5시간 전까지"로 적었다. 대표 진술("하루 전이나 5시간 전")을 이렇게 해석한 것이 맞는가.
- [ ] **누적 판매 10,000개 삭제** — 삭제해도 되는가.
